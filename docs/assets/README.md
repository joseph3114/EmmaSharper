# Assets

Brand-ish artefacts for the repository and package. Neither is generated by the build,
so both are committed here rather than produced on demand.

| File | Where it is used | How to change it |
|---|---|---|
| `social-preview.png` | GitHub link previews | **Settings → General → Social preview → Edit.** Uploading is the only way — GitHub exposes no API for it. |
| [`../../icon.png`](../../icon.png) | the nuget.org package listing | `PackageIcon` in `src/EmmaSharper/EmmaSharper.csproj`; ships **inside** the `.nupkg`. |

## Two things worth knowing before editing either

**The package icon is immutable once published.** It travels inside the `.nupkg`, so a
replacement only reaches users in a new package version. The social preview is the
opposite — it lives on GitHub's side and updates the moment you upload, on every existing
link. Do not assume a change to one behaves like a change to the other.

**Neither uses Emma's branding, deliberately.** Emma publishes no brand assets, and the
README states this project is not affiliated with them; shipping their marks would imply
an endorsement that does not exist. The `ES` lettermark reads as *EmmaSharper* rather than
*Emma*, which is the point — a bare `E` invites the misreading that this is a first-party
client.

The slate is `#2E3E4F`, chosen to be recognisably neutral rather than any institution's
colour.
